
# Expense Tracker

Expense Tracker is a modern web application for managing and tracking your expenses. Built with Vue 3 and Vite, it provides a fast, responsive, and user-friendly experience.

## Tech Stack

- **Vue 3**: Frontend framework
- **Vite**: Build tool
- **PrimeVue**: UI component library
- **TailwindCSS**: Utility-first CSS framework
- **TypeScript**: Application logic

## Getting Started

### Clone the repository

```sh
git clone https://github.com/your-username/expense-tracker.git
cd expense-tracker
```

### Install dependencies

```sh
npm install
```

### Run the development server

```sh
npm run dev
```

### Build for production

```sh
npm run build
```
